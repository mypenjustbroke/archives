MediaWiki 1.24 and newer no longer automatically enables installed skins (see Manual: Skin autodiscovery). You can paste the following lines into LocalSettings.php to enable all installed skins:
wfLoadSkin( 'MinervaNeue' );
wfLoadSkin( 'MonoBook' );
wfLoadSkin( 'Timeless' );
wfLoadSkin( 'Vector' );

Minecraft Server Legal Foundation Act

Passed by the Senate on 14 February 2025.

Preamble

Whereas: The current legislation for the Minecraft Server has a number of omissions.

Whereas: The Minecraft Server should have a more stable legal foundation.

The following act is hereby proposed.

Article 1: Governance

§1. A #minecraft-announcements channel shall be created within the SimDemocracy Discord.

§1.1. Permission to send messages in this channel shall be restricted to the Minecraft Server Owner, the Minecraft Oversight Committee, the Governor of the Minecraft Server, and anyone granted permission by the Governor of the Minecraft Server.

§2. The following must be announced in the #minecraft-announcements channel:

§2.1. All executive orders issued by the Governor of the Minecraft Server
§2.2. All punishments and bans issued on the Minecraft Server
§2.3. The written explanation of an invocation of emergency powers as required by the Minecraft Server Transfer Act or other applicable legislation
§2.4. Reports and decisions made by the Minecraft Oversight Committee

§3. The Governor of the Minecraft Server shall have the authority to delegate their powers and responsibilities via executive order as they see fit.

§4. The Governor of the Minecraft Server is permitted, but not required, to provide assistance to governments and members of the Minecraft Server outside of SimDemocracy’s jurisdiction at their request.

Article 2: Requests to the Minecraft Server Owner

§1. The Governor of the Minecraft Server shall have the power to request that the Minecraft Server Owner implement changes to the server that the Governor of the Minecraft Server is incapable of implementing on their own.

§1.1. These requests must be posted in the #minecraft-questions channel.

§2. The Minecraft Server Owner will have the responsibility of responding to all requests made by the Governor of the Minecraft Server.

§2.1. These responses must be posted in the #minecraft-questions channel.
§2.2. A valid response will consist of either a confirmation that the request has been implemented or a rejection of the request accompanied by an explanation of why implementing the request is unreasonable, illegal, or impossible.

§3. The Minecraft Oversight Committee shall have the authority, but not the obligation, to review all rejected requests.

§4. The Minecraft Server Owner shall have 7 days to respond to a request made by the Governor of the Minecraft Server.

Article 3: Joining the Minecraft Server

§1. The Minecraft Server Owner shall be responsible for ensuring that the server is available to join for as many people as is reasonably possible, excluding banned individuals.

§1.1. Unless it is technically infeasible to do so, the server should support players joining on Java Edition, Bedrock Edition, and console releases of Minecraft.
§1.2. The server must not require clients to install any mods in order to join.
§1.3. Optimization and cosmetic client-side mods such as Lithium and Zoomify shall not be prohibited.
